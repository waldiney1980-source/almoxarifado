1 Visão geral

O que este sistema faz por você

É o controle de estoque das peças da manutenção do NorteShopping. Ele roda direto no navegador — sem instalar nada, sem internet obrigatória — e organiza toda a operação do almoxarifado em um só lugar.

Sabe o que tem em estoque

Quantidade atual de cada peça, valor em reais e onde ela está guardada.

Avisa o que está acabando

Semáforo de cores e alertas quando o estoque cai abaixo do mínimo.

Monta a lista de compras

Cria sozinho as solicitações de reposição, com quantidade sugerida.

Registra cada movimento

Todo lançamento de entrada e saída fica gravado com data e observação.

9 Estoque crítico

O semáforo de cores

Para saber o que precisa de atenção sem pensar, o sistema pinta cada peça com uma cor conforme o estoque atual em relação ao mínimo.

Verde · OK

Estoque confortável, acima do mínimo. Nada a fazer.

Amarelo · Atenção

Chegando perto do mínimo (até 10% acima). Fique de olho.

Vermelho · Crítico

No mínimo ou abaixo. Precisa repor — já vira solicitação de compra.

🎯
A tela Estoque Crítico lista somente as peças vermelhas e amarelas, então você olha direto o que importa, sem rolar a lista inteira de 500 itens.

11 Indicadores

Conforme você registra as saídas, o sistema aprende o ritmo de consumo e passa a estimar quando cada peça vai acabar — para você comprar antes de faltar.

Consumo de 30 e 90 dias

Quanto de cada peça saiu no período recente.

Dias até faltar

Estimativa de quantos dias o estoque atual ainda dura.

Previsão de ruptura

Alerta das peças em rota de acabar em breve.

“Comprar hoje”

Cruza consumo × lead time e diz o que já não pode esperar.

📈
Quanto mais fiel for o registro de saídas, mais precisos ficam esses números. Nos primeiros dias eles ainda estarão “aprendendo” — é normal.

14 A regra de ouro

Backup: nunca perca seus dados

Como os dados vivem só no navegador, o backup é a sua rede de segurança. Ele gera um arquivo com tudo — itens, movimentações e compras — que você guarda em lugar seguro.

Exportar Backup

Gera um arquivo .json. Guarde-o numa pasta da rede ou do OneDrive — não deixe só no PC.

📆
Faça isso toda semana (ou todo dia, se o movimento for grande). Vale o hábito: sexta-feira, antes de sair, exporte.

Importar Backup

Restaura tudo a partir de um arquivo salvo. Use se trocar de computador, limpar o navegador ou precisar recuperar os dados.

⚠️
Importar um backup substitui o que estiver na tela. Tenha certeza de que é a versão certa.
💾
Regra prática: Excel para relatório, JSON para segurança. É o backup JSON que devolve o sistema exatamente como estava.
15 Operação

Como operar bem no dia a dia

Quatro hábitos que mantêm o controle confiável e evitam confusão entre computadores.

Uma estação oficial

Lance entradas e saídas sempre no mesmo PC e navegador. Essa é a base verdadeira.

Backup toda semana

Exporte o JSON e guarde na rede. É o seguro contra qualquer perda.

Lance na hora

Registre a saída no momento em que a peça sai. Deixar para depois é como o estoque fica errado.

Para compartilhar

Quem só consulta abre o link e importa o backup mais recente — sem lançar nada, para não gerar conflito.

🤝
O sistema não é multiusuário em tempo real: dois computadores não se sincronizam sozinhos. Se mais de uma pessoa precisa lançar, façam na mesma estação — ou troquem a base pelo arquivo de backup.
16 Dúvidas rápidas

Perguntas frequentes

P. Preciso de internet para usar?
Só para abrir o link na primeira vez. Depois de carregado, ele funciona mesmo offline — os dados estão no seu navegador.
P. Apaguei um item / lancei errado. E agora?
Para item, use editar ou exclua e cadastre de novo. Para movimentação errada, lance o movimento contrário (uma entrada compensa uma saída indevida). E, se tiver backup recente, dá para restaurar.
P. Sumiram meus dados ao abrir noutro PC.
Não sumiram: cada PC/navegador tem a própria base. Leve os dados com o arquivo de backup e use “Importar Backup” na outra máquina.
P. Posso mudar o estoque mínimo/máximo?
Sim, a qualquer momento, na edição do item. Isso ajusta o semáforo e a quantidade sugerida de compra.
